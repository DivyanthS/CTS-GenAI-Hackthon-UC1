# CTS GenAI Healthcare Claims Fraud Detection

An AI-powered healthcare claims analysis and fraud-risk detection platform.

## Technology Stack

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS
- TanStack Query
- Recharts

### Backend
- Python
- Flask
- Pydantic
- Pandas
- XGBoost

### Machine Learning
- Provider-level fraud-risk prediction
- Claim-level analysis
- Statistical feature engineering
- Risk scoring

## Running the Frontend

```bash
npm install
npm run dev
